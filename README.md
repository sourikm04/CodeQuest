# CodeQuest 2025

Greetings to **CodeQuest 2025**, an interactive and visually appealing website meant to present event information with ease of use and intriguing animations. Created solely from **HTML, CSS, and JavaScript**, this frontend project provides a seamless and engaging user experience on every device.

## 🔒 Features
- **Introdction Page** – A friendly and visually stunning welcome to CodeQuest 2025.
- **Venue Page** – Information about the event venue in detail.
- **Schedule Page** – A clear-cut calendar of activities and sessions.
- **Rules & Eligibility Page** – Explicitly written criteria for participants to be allowed in.
- **Register Page** – Convenient registration procedure for participants willing to attend.
- **Contact Page** – Convenient access to event planners for inquiries and help.

## 🎨 Design & Animation
The site is completely **responsive**, allowing for optimal viewing across varying screen sizes. Smooth **animations** are used to create a more enjoyable user experience, making it easy to navigate and intuitive.

## 🌐 Technologies Used
- **HTML** – Website structure and content layout.
- **CSS** – Styling of elements using animations and responsive layout.
- **JavaScript** – Adding interactivity and dynamic behavior to content.

## 🚀 Experience the Website
CodeQuest 2025 is designed to be beautiful, functional, and easy to use. Whether you're viewing event information or registering as an attendee, this site provides a smooth experience with interactive animations and contemporary UI design.
